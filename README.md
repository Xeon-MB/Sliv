# Sliv⚔️

Um jogo 2D desenvolvido na **Godot Engine**, com combate, inimigos e uma aventura em um mundo vivo.

## 🎮 Sobre o jogo

O jogador precisa enfrentar slimes usando uma espada, administrar sua vida e derrotar os inimigos para completar o desafio.

## ✨ Funcionalidades

- ⚔️ Combate com espada
- 🟢 Inimigos do tipo slime
- ❤️ Sistema de vida
- ☠️ Tela de derrota
- 🏆 Tela de vitória
- 📊 Contador de inimigos derrotados

## 🛠️ Tecnologias

- Godot Engine 4
- GDScript

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Abra o Godot Engine.
3. Importe o projeto pelo arquivo `project.godot`.
4. Execute o jogo.
